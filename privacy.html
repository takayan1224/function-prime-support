function Pop プライバシーポリシー

制定日：2026年11月8日

function Pop（以下「本アプリ」）は、利用者のプライバシーを大切に扱います。本ポリシーでは、本アプリが扱う情報とその使い方について説明します。

1. 本アプリが扱う情報

  • Game Center のプレイヤー ID と得点：ランキングに表示するため、Apple の Game Center に送られます。
  • ランキング用の名前：利用者が入力した場合のみ、Game Center のプレイヤー ID と一緒に Apple の iCloud（CloudKit の公開データベース）に保存され、ランキングでほかの利用者に表示されます。
  • 通報の内容：不適切な名前を通報したとき、通報された名前とプレイヤー ID が iCloud に保存されます。開発者が内容を確認し、ふさわしくない名前はランキングに表示されないようにします。

2. 端末の中だけに保存する情報

自己ベスト、設定、チュートリアルの進み具合、自分で隠した名前は、利用者の端末の中だけに保存され、外部へは送られません。

3. 集めない情報

氏名、メールアドレス、電話番号、位置情報、連絡先、写真などは集めません。本アプリには、広告、外部の解析ツール（アクセス解析・クラッシュ解析の SDK 等）、トラッキングの仕組みは含まれていません。開発者が運営する独自のサーバーへ情報を送ることもありません（表示しない名前の一覧を、このサポートサイトから読み込むだけです）。

4. 情報の使い方

集めた情報は、ランキングの表示と、不適切な名前への対応のためだけに使います。第三者に販売・提供することはありません。

5. 情報の削除

ランキング用の名前の削除を希望する場合は、下記のお問い合わせ先までご連絡ください。本アプリを削除すると、端末の中に保存された情報は消去されます。Game Center の記録は、Apple の Game Center の設定から管理できます。

6. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更した場合は、このページでお知らせします。
