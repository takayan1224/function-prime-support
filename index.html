遊び方

x²1e^xsin x
  • 4つのマスに入った関数をぜんぶ足したものが f(x) です。最初は x と 1 から始まります。
  • 毎ラウンド3枚のカードがランダムに配られます。好きな順番で使い、残りが1枚以下になったら → で次のラウンドへ進みます。
  • x：1マスに x を掛けます（空きマスには x を置きます）。1：1マスに 1 を足します。
  • d/dx：全部のマスをいっぺんに微分します。∫：選んだ1マスだけを積分します（積分定数は 0）。
  • f(1)・f(2)：x に 1 または 2 を代入した全体の値が得点になります。そのかわり、値がいちばん大きいマスが1つ消えます。
  • 使わないカードは、しおりマークで1枚だけ次のラウンドへ持ち越せます。
  • ときどき空きマスが黄金マスになります。黄金マスの値は10倍に数えます。小鳥が x を運んでくることも。
  • 全部のマスが 0 になったらゲームオーバーです。ラウンドに終わりはありません。

はじめて起動したときは、ルールを1つずつ体験できるチュートリアルが始まります。ホーム画面の「チュートリアル」からいつでも見直せます。

よくある質問

ランキングに参加できません

iPhone の「設定 → Game Center」でサインインしてください。ランキング用の名前を保存するには、iCloud へのサインインも必要です。

ランキングの名前を変えたい

ホーム →「ランキング」→「ランキングの名前を変える」から変更できます（10文字まで）。

不適切な名前を見つけました

ランキングでその名前を長押しし、「この名前を通報」を選んでください。運営が確認し、ふさわしくない名前は表示を消します。すぐに見えなくしたいときは「この人の名前を隠す」を選ぶと、あなたの画面でだけ隠れます。

置けるカードがなくて進めません

全部のマスが埋まっていて、残りのカードがどこにも置けないときは、→ でそのまま次のラウンドへ進めます。

料金はかかりますか？

無料です。アプリ内課金や広告はありません。
